# SecureChat

E2EE মেসেজিং ওয়েব অ্যাপ। দুটো অংশ:

- `api/` : Cloudflare Worker (D1 + Durable Objects + KV)
- `web/` : React + Vite + Tailwind ফ্রন্টএন্ড

## লোকাল চালানো

```bash
cd api && npm install && npm run db:local && npm run dev     # টার্মিনাল ১
cd web && npm install && npm run dev                         # টার্মিনাল ২
```

## GitHub দিয়ে Cloudflare-এ ডিপ্লয়

### ১. রিসোর্স তৈরি (একবার)
1. Cloudflare Dashboard → Storage & Databases → D1 → Create database, নাম `securechat-db`।
   `database_id` কপি করে `api/wrangler.jsonc`-এ `REPLACE_WITH_YOUR_D1_DATABASE_ID`-এর জায়গায় বসান।
2. D1 ডাটাবেজের Console ট্যাবে `api/schema.sql`-এর পুরো লেখা পেস্ট করে চালান।
3. KV → Create namespace, নাম `securechat-media`। ID কপি করে `api/wrangler.jsonc`-এ
   `REPLACE_WITH_YOUR_KV_NAMESPACE_ID`-এর জায়গায় বসান। (কার্ড লাগে না; ফাইল ৩০ দিনে নিজে মুছে যায়।)

### ২. GitHub-এ আপলোড
```bash
git init && git add . && git commit -m "init"
git branch -M main
git remote add origin https://github.com/YOU/securechat.git
git push -u origin main
```

### ৩. API ডিপ্লয়
Workers & Pages → Create → Import a repository → রিপো বেছে নিন।
- Project name: `securechat-api` (wrangler.jsonc-এর `name`-এর সঙ্গে মিলতে হবে)
- Root directory: `api`
- Build command: খালি রাখুন
- Deploy command: `npx wrangler deploy`

ডিপ্লয় শেষে URL পাবেন, যেমন `https://securechat-api.xxxx.workers.dev`

### ৪. ওয়েব ডিপ্লয়
একই রিপো থেকে আরেকটা প্রজেক্ট:
- Project name: `securechat-web`
- Root directory: `web`
- Build command: `npm run build`
- Deploy command: `npx wrangler deploy`
- Build variables: `VITE_API_URL` = আপনার API URL (শেষে `/` নয়)

### ৫. CORS শক্ত করা
`api/wrangler.jsonc`-এ `ALLOWED_ORIGIN` এর মান ওয়েবের URL করে (যেমন `https://securechat-web.xxxx.workers.dev`) commit ও push করুন।

## ধাপ ৮: নিরাপত্তা ও PWA (এই ভার্সনে যোগ হয়েছে)
- লগইন/রেজিস্টার/আপলোডে রেট লিমিট (D1 কাউন্টার), পাসওয়ার্ড সর্বোচ্চ ২০০ অক্ষর।
- WebSocket-এ সেশন টোকেনের বদলে ৩০ সেকেন্ডের এক-বারের টিকেট।
- প্রতি কানেকশনে মেসেজ রেট লিমিট, প্রতি ইনবক্সে সর্বোচ্চ ৫০০টি অপেক্ষমাণ মেসেজ।
- প্রতিদিন (cron) মেয়াদোত্তীর্ণ সেশন/টিকেট/কাউন্টার মুছে ফেলা।
- ওয়েবে CSP ও নিরাপত্তা হেডার (`web/public/_headers`), হোম স্ক্রিনে ইনস্টলযোগ্য PWA।

**আগে ডিপ্লয় করে থাকলে:** D1 Console-এ `api/schema.sql` আবার চালান (নতুন দুটো টেবিল যোগ হবে, পুরনো ডেটা থাকবে), তারপর push করুন।

## ধাপ ৯: ডেলিভারি টিক ও ভয়েস মেসেজ
- টিক: 🕓 পাঠানো হচ্ছে, ✓ সার্ভার নিয়েছে, ✓✓ প্রাপকের ডিভাইসে পৌঁছেছে, নীল ✓✓ পড়েছে, ⚠ পাঠানো যায়নি।
  পৌঁছেছে/পড়েছে রিসিপ্ট এনক্রিপ্টেড মেসেজ হিসেবে যায়, সার্ভার শুধু অর্থহীন ডেটা দেখে। সার্ভারে কোনো বদল নেই, শুধু ওয়েব ডিপ্লয় করলেই হয়।
- ভয়েস মেসেজ: ইনপুট ফাঁকা থাকলে 🎤 বাটন। চাপলে রেকর্ড শুরু, ➤ দিলে এনক্রিপ্ট হয়ে যায়, 🗑 দিলে বাতিল। সর্বোচ্চ ৫ মিনিট।
  ভয়েস সাধারণ ফাইলের মতো KV-তে এনক্রিপ্টেড থাকে, প্রতিটিতে একটা KV লেখা খরচ হয়।

## ধাপ ১০: ইমেইল OTP রেজিস্ট্রেশন, প্রোফাইল ও পাসওয়ার্ড রিসেট
রেজিস্ট্রেশন: পুরো নাম, ইমেইল, পাসওয়ার্ড (+কনফার্ম) → ইমেইলে ৬ সংখ্যার কোড (১০ মিনিট) → ভেরিফাই → username ও প্রোফাইল ছবি।
লগইন ইমেইল বা username দিয়ে। "পাসওয়ার্ড ভুলে গেছেন?" থেকে ইমেইল কোড দিয়ে রিসেট (সব ডিভাইস থেকে লগআউট হয়)।

### ইমেইল পাঠানোর সেটআপ (Brevo, ফ্রি, কার্ড লাগে না)
1. brevo.com-এ অ্যাকাউন্ট খুলুন। Senders, Domains & Dedicated IPs → Senders → আপনার একটা ইমেইল প্রেরক হিসেবে যোগ করে ভেরিফাই করুন।
2. SMTP & API → API keys → নতুন key বানান।
3. Cloudflare → `securechat-api` Worker → Settings → Variables and Secrets-এ **Secret** টাইপে দিন:
   - `BREVO_API_KEY` = ওই key
   - `MAIL_FROM` = ভেরিফাই করা প্রেরকের ইমেইল
   - (ঐচ্ছিক) `MAIL_FROM_NAME` = SecureChat
4. ফ্রি প্ল্যানে দিনে প্রায় ৩০০টি ইমেইল। নতুন Brevo অ্যাকাউন্ট চালু হতে ঘণ্টাখানেক বা বেশি লাগতে পারে, আর Gmail ঠিকানা প্রেরক হলে ইমেইল স্প্যামে যেতে পারে।
লোকালে টেস্টে `api/.dev.vars.example` কপি করে `.dev.vars` বানান, তাহলে কোড টার্মিনালে ছাপা হবে।

### ডাটাবেজ আপডেট (আগে ডিপ্লয় করে থাকলে)
D1 Console-এ `api/migrations/002_accounts.sql` **একবার** চালান। পুরনো অ্যাকাউন্ট থাকবে ও username দিয়ে লগইন চলবে (তাদের ইমেইল নেই, তাই রিসেট করা যাবে না)।
নতুন ডাটাবেজ হলে শুধু `schema.sql` চালান।

## ধাপ ১১: নোটিফিকেশন
- **Web Push:** অ্যাপ বন্ধ বা ব্যাকগ্রাউন্ডে থাকলেও "নতুন মেসেজ এসেছে" আসে। হোম স্ক্রিনের 🔔 থেকে চালু করতে হয়।
  পুশ পেলোড ছাড়া যায় (এন্ড-টু-এন্ড এনক্রিপশন বজায় রাখতে), তাই প্রেরকের নাম বা মেসেজ দেখায় না। অ্যাপ সামনে খোলা থাকলে নোটিফিকেশন আসে না।
- **অ্যাপের ভেতরে:** অন্য চ্যাটে মেসেজ এলে ছোট শব্দ (বন্ধ করা যায়), ট্যাব টাইটেলে ও ইনস্টল করা অ্যাপের আইকনে আনরিড সংখ্যা।
- VAPID কী সার্ভার নিজে প্রথমবার বানিয়ে D1-এ রাখে। আলাদা কী বা secret লাগে না।
- iPhone-এ শুধু "Add to Home Screen" করা অ্যাপ থেকে কাজ করে।
- **ডাটাবেজ:** D1 Console-এ `api/migrations/003_push.sql` একবার চালান।

## ধাপ ১২: মেসেজ অ্যাকশন
- মেসেজ **ডানে সোয়াইপ** করলে রিপ্লাই। **চেপে ধরলে** (ডেস্কটপে রাইট-ক্লিক) মেনু: রিঅ্যাকশন (👍❤️😂😮😢🙏), উত্তর, কপি, ফরওয়ার্ড, পিন, এডিট (নিজের টেক্সট মেসেজ, ১৫ মিনিটের মধ্যে), ডিলিট (আমার থেকে বা সবার থেকে)।
- রিঅ্যাকশন, এডিট, ডিলিট, পিন এনক্রিপ্টেড কন্ট্রোল মেসেজ হিসেবে যায়, সার্ভার কিছু দেখে না; এতে নোটিফিকেশন যায় না। সার্ভারে কোনো বদল নেই।
- ফাইল ফরওয়ার্ড করতে ফাইলটা আগে ডাউনলোড হয়ে থাকতে হবে (আবার এনক্রিপ্ট করে আপলোড হয়)।

## ধাপ ১৩: আইকন ও ছবি পাঠানো

## ধাপ ১৪: হোম পেজের মেনু ও ফ্লোটিং বাটন
- নতুন চ্যাটের "+" এখন নিচে ডানে ভাসমান বাটন (FAB)।
- উপরে তিন-ডট মেনু: অ্যাকাউন্ট (নাম, username, ইমেইল, ছবি বদল), প্রাইভেসি (পড়েছি রিসিপ্ট চালু/বন্ধ, কী ফিঙ্গারপ্রিন্ট, এই ডিভাইসের চ্যাট মোছা), সেটিংস (নোটিফিকেশন ও শব্দ), লগআউট।

## ধাপ ১৫: নাম, ইমেইল, পাসওয়ার্ড, username বদলানো
মেনু → অ্যাকাউন্ট থেকে। নাম সরাসরি; পাসওয়ার্ড বর্তমান পাসওয়ার্ড দিয়ে (অন্য ডিভাইস লগআউট হয়); ইমেইল বর্তমান পাসওয়ার্ড + নতুন ঠিকানায় কোড দিয়ে (পুরনো ঠিকানায় সতর্কবার্তা যায়);
username বর্তমান পাসওয়ার্ড দিয়ে (মাসে একবার, পুরনো নাম ৩০ দিন সংরক্ষিত)। বদলালে এই ডিভাইসের ইতিহাস নতুন নামে সরে যায় এবং কন্টাক্টদের এনক্রিপ্টেড বার্তায় জানানো হয়, তারা কী মিলিয়ে নিজেদের চ্যাট সরিয়ে নেয়।
**ডাটাবেজ:** D1 Console-এ `api/migrations/004_username_holds.sql` একবার চালান।

## ধাপ ১৬: তারিখ-বিভাজক, নিচে যাওয়ার বাটন, ধীরে ধীরে লোড
- চ্যাটে দিন বদলালে "আজ / গতকাল / সপ্তাহের বার / পুরো তারিখ" চিপ বসে। চ্যাট লিস্টে "গতকাল" লেখা দেখায়।
- উপরে স্ক্রোল করলে নিচে ডানে ↓ বাটন আসে, এক চাপে সর্বশেষ মেসেজে যায়; উপরে থাকা অবস্থায় নতুন মেসেজ এলে বাটনে সংখ্যা দেখায়।
- চ্যাট খুললে শেষ ৪০টি মেসেজ আসে, উপরে গেলে ৩০টি করে পুরনো মেসেজ লোড হয় (চোখের জায়গা না নড়ে)।

## ধাপ ১৭: অ্যাকাউন্ট/প্রাইভেসি/সেটিংস পেজ, ভাষা ও থিম
- হোমের ডানের প্রোফাইল ছবি → **প্রোফাইল পেজ**: প্রোফাইল ছবি, কভার ফটো, নাম, username, bio; উপরে "ইডিট" বাটন (username বদলানো আলাদা, পাসওয়ার্ড লাগে)।
- মেনু → **প্রাইভেসি**: ইমেইল ও পাসওয়ার্ড বদলানো, পড়েছি রিসিপ্ট, কী ফিঙ্গারপ্রিন্ট, ডিভাইসের চ্যাট মোছা।
- মেনু → **সেটিংস**: পারমিশন (মাইক্রোফোন, নোটিফিকেশন), ভাষা (সিস্টেম/English/বাংলা), থিম (সিস্টেম/ডার্ক/লাইট)।
- ভাষা: স্ক্রিনের বাংলা লেখা `src/en.ts`-এর অভিধান দিয়ে অনুবাদ হয় (নিজস্ব JSX রানটাইম `src/i18n-jsx`)। নতুন বাংলা লেখা যোগ করলে `en.ts`-এও এন্ট্রি দিন, নইলে ইংরেজিতে বাংলাই দেখাবে।
- থিম: `index.css`-এ রঙের ভেরিয়েবল উল্টে লাইট থিম।
- **ডাটাবেজ:** D1 Console-এ `api/migrations/005_profile_fields.sql` একবার চালান।

- লগইন ব্যর্থ হলে অনুবাদ-ফাংশন ঢেকে যাওয়ার বাগ ঠিক (`App.tsx`)। ProfileSetup-এর পুরনো "username বদলানো যাবে না" লেখা ঠিক।
- মিডিয়া DELETE-এ প্রেরক/প্রাপক যাচাই। `/api/users/` ও `/api/profile`-এ রেট লিমিট, ভুল `%` এনকোডিংয়ে আর 500 নয়, avatar base64 যাচাই।
- OTP-র চেষ্টা গণনা atomic, কোড/পাসওয়ার্ড তুলনা ধ্রুবক-সময়ে, অচেনা ইউজারেও হ্যাশ চলে (সময় দেখে অনুমান বন্ধ)। লগইন লিমিট ident+IP জোড়ায়, তাই অন্যজন আপনার অ্যাকাউন্ট লক করতে পারে না।
- কন্টাক্টের কী বদলালে (ভেরিফাই না করা হলেও) চ্যাটে লাল সতর্কতা ও "মেনে নিলাম" বাটন।
- ইনবক্সে কাউন্টার: প্রতিবার ৫০০ সারি পড়া বন্ধ (খরচ কম); এক প্রেরক সর্বোচ্চ ১৫০টি জমা রাখতে পারে, তাই একজন পুরো ইনবক্স ভরতে পারে না।
- IndexedDB-র একটাই কানেকশন ক্যাশ হয়। iPhone-এ পুশ সাবস্ক্রিপশন টিকিয়ে রাখতে অ্যাপ খোলা থাকলেও নোটিফিকেশন দেখিয়ে সঙ্গে সঙ্গে বন্ধ হয়।
- **আপনাকে করতে হবে:** (১) Worker-এ `VAPID_SUBJECT` = `mailto:আপনার-ইমেইল` দিন (নইলে `MAIL_FROM` ব্যবহার হয়)। (২) `api/wrangler.jsonc`-এ `ALLOWED_ORIGIN` ওয়েবের URL করুন। (৩) `web/public/_headers`-এ `connect-src` নিজের API হোস্টে সীমিত করুন (ওপরের মন্তব্য দেখুন)। ডাটাবেজে কোনো বদল নেই।

## ধাপ ১৯: অন্যের প্রোফাইল দেখা
- চ্যাটের হেডারে নাম বা ছবিতে চাপলে প্রোফাইল পেজ (`#u/username`) খোলে, ব্যাক বাটনে চ্যাটে ফেরা যায়: ছবি, নাম, @username, bio। সেখান থেকে সেফটি নাম্বার মেলানো ও শুধু এই ডিভাইস থেকে ওই চ্যাট মোছা যায়।
- ইমেইল কাউকে দেখানো হয় না। অনলাইন স্ট্যাটাস কে দেখবে তা প্রাইভেসি পেজে ঠিক করা যায় (সবাই / যাদের সঙ্গে চ্যাট করেছি / শুধু আমি)। ডিফল্ট: অনলাইন স্ট্যাটাস সবাই। সার্ভার নিজেই এই সেটিং মানে, ক্লায়েন্ট ফিল্টার করে না।
- চ্যাটের ছবি ও প্রোফাইল ছবি (অন্যের ও নিজের) চাপলে ফুল স্ক্রিন ভিউ: ছবিতে চাপলে জুম, বাইরে চাপলে/Esc/ব্যাক বাটনে বন্ধ; চ্যাটের ছবিতে ডাউনলোড বাটনও আছে।
- ডাটাবেজে কোনো বদল নেই, শুধু API ও ওয়েব ডিপ্লয় করুন।

## জানা সীমাবদ্ধতা

- ফরওয়ার্ড সিক্রেসি নেই (Double Ratchet নেই), কী ভেরিফিকেশন ম্যানুয়াল।

## সাম্প্রতিক সংশোধন ও জানা সীমাবদ্ধতা

**সংশোধন**
- একই অ্যাকাউন্ট অন্য ডিভাইসে খুললে সার্ভারের কী বদলে যায়। এখন পুরনো ডিভাইসে হলুদ নোটিশ আসে ("এই ডিভাইসে ব্যবহার করুন"), আর সেই ডিভাইস মেসেজ ack করে মুছে ফেলে না, ফলে মেসেজ হারায় না। সরাসরি লগইন করলে সেই ডিভাইসের কী সার্ভারে বসে; পেজ রিফ্রেশে চুপচাপ কেড়ে নেওয়া হয় না।
- ডিক্রিপ্ট ব্যর্থ হলে পিয়ারের নতুন কী এনে আরেকবার চেষ্টা করা হয়।
- পাঠানো মেসেজ ২০ সেকেন্ডে 'sent' না হলে ⚠ দেখায় ও "আবার পাঠান" বাটন আসে। আগের সেশনে আটকে থাকা 🕓 মেসেজও ⚠ হয়ে যায়।
- মেসেজ ইনপুটে ৫০০০ অক্ষরের সীমা (রিসিভার এর বেশি কেটে ফেলত)।
- পিয়ারের কী বদলালে (মেনে না নেওয়া পর্যন্ত) নতুন মেসেজ/ফাইল পাঠানো আটকে যায়।
- `/api/media`-তে প্রতি ইউজার দিনে ১৫০টি আপলোড (KV-র ফ্রি লেখার সীমা বাঁচাতে); `ws-ticket`-এও রেট-লিমিট।
- রেজিস্টারে ইমেইল আগেই থাকলে সেটা রেসপন্সে জানানো হয় না, আসল মালিককে ইমেইলে জানানো হয়।
- প্রোফাইল ছবি সরানো যায় (অ্যাকাউন্ট → ইডিট → "ছবি সরান")।
- **অ্যাকাউন্ট ডিলিট** (প্রাইভেসি পেজ): সার্ভারের ডেটা, জমা মেসেজ ও এই ডিভাইসের চ্যাট/কী মোছে; username ৩০ দিন সংরক্ষিত থাকে। KV-তে থাকা এনক্রিপ্টেড ফাইল ৩০ দিনে নিজে মুছে যায়।
- ইংরেজি মোডে ইউজারের মেসেজ/নাম/bio আর অনুবাদ হয় না।
- `i18n-jsx` রানটাইমে `JSX` টাইপ এক্সপোর্ট যোগ হয়েছে (`npm run typecheck`-এর জন্য)।

**সীমাবদ্ধতা (জেনে রাখুন)**
- একসঙ্গে একটাই ডিভাইস সক্রিয় থাকে (কী ডিভাইসের ব্রাউজারে থাকে)। ব্রাউজার ডেটা মুছলে পুরনো চ্যাট ফেরে না।
- এনক্রিপশন স্ট্যাটিক ECDH P-256 → HKDF-SHA256 → AES-GCM: ফরওয়ার্ড সিক্রেসি নেই (Signal-এর মতো নয়)।
- সার্ভার কী-র সঠিকতা নিশ্চিত করে না; সেফটি নাম্বার মিলিয়ে নিলে তবেই নিশ্চিত।

## চ্যাটে লিংক, সোশ্যাল মিডিয়া, YouTube ও @username

- **ওয়েবসাইট লিংক:** `https://...`, `www....` এবং পরিচিত সোশ্যাল সাইটের খালি ঠিকানা (যেমন `facebook.com/...`) ক্লিকযোগ্য হয়, নতুন ট্যাবে খোলে (`noopener noreferrer nofollow`)। শুধু `http/https` চলে। `https://facebook.com@evil.com` ধরনের ছদ্মবেশী লিংক, `javascript:` ও আইপি-ঠিকানার লিংক লিংক হয় না। অস্বাভাবিক (IDN/`xn--`) ডোমেইনের আগে ⚠ বসে।
- **সোশ্যাল মিডিয়া:** Facebook, Instagram, X/Twitter, TikTok, Telegram, WhatsApp, LinkedIn, GitHub, Reddit, Pinterest, Threads, Snapchat, Discord ও YouTube লিংকের নিচে নামসহ কার্ড আসে। ডোমেইন মিলিয়ে চেনা হয় (`facebook.com.evil.com` কার্ড পায় না)।
- **YouTube:** `youtu.be`, `watch?v=`, `shorts`, `live`, `embed` লিংকের নিচে প্লেয়ার কার্ড (`t=1m30s` ধরলে সেখান থেকে শুরু)। গোপনীয়তার জন্য থাম্বনেইলও আগে লোড হয় না। "ভিডিও চালান" ট্যাপ করলে তবেই `youtube-nocookie.com` থেকে প্লেয়ার লোড হয়। এজন্য `web/public/_headers`-এর CSP-তে `frame-src https://www.youtube-nocookie.com` যোগ হয়েছে। সেটা ডিপ্লয়ের সময় আপনার নিজের `_headers` ব্যবহার করলে ঠিক আছে কিনা দেখে নিন।
- **@username:** মেসেজে `@rahim_12` ট্যাপ করলে তার প্রোফাইল খোলে (ইউজার না থাকলে "ইউজার পাওয়া যায়নি", নিজের নাম হলে নিজের অ্যাকাউন্ট পেজ)। প্রোফাইল পেজে "মেসেজ করুন" বাটন আছে। ইমেইল (`a@b.com`) ভুল করে মেনশন হয় না।
- লিংক শনাক্তের যুক্তি `web/src/linkparse.ts`-এ, UI `web/src/RichText.tsx`-এ। এই সব প্রক্রিয়া শুধু রিসিভারের ডিভাইসে হয়, সার্ভার লিংকের কিছুই দেখে না।

## অ্যাপ স্টাইলহীন (সাদা পাতায় সাধারণ লেখা) দেখালে

সার্ভিস ওয়ার্কার পুরনো/ভুল CSS ফাইল ক্যাশ করে রাখলে এমন হতে পারে। `sw.js`-এ এখন শুধু সফল, HTML-নয় এমন ফাইল ক্যাশ হয় এবং ক্যাশের নাম `securechat-v3` (পুরনো ক্যাশ নিজে মুছে যায়)। নতুন সংস্করণ ডিপ্লয়ের পর একবার পেজ রিলোড করুন। তবুও না হলে ব্রাউজারে সাইট সেটিংস → "Clear & reset" করুন বা ইনকগনিটোতে খুলে দেখুন।
- চ্যাটের হেডারে ছবির কোণায় অনলাইন বিন্দু (সবুজ অনলাইন, ধূসর অফলাইন; মালিক স্ট্যাটাস লুকালে বিন্দু আসে না)। অন্যের প্রোফাইল পেজও এখন নিজের পেজের মতো: ছবি বামে, পাশে নাম, @username ও অনলাইন/সর্বশেষ দেখা।
- চ্যাট হেডারে নামের নিচের অনলাইন/সর্বশেষ দেখা লেখা সরানো হয়েছে (শুধু ছবির কোণার বিন্দু থাকে; লেখাটা প্রোফাইল পেজে আছে)। অন্যের প্রোফাইল পেজে (`#u/username`) রিফ্রেশ করলে এখন প্রোফাইল পেজেই থাকে, আগে চ্যাটে চলে যেত।

## ছবি/কভার আপলোড সংশোধন

- ফাইল বেছে নেওয়ার পর আগে ফাইল মেমরিতে পড়ে নেওয়া হয়, তারপর ইনপুট খালি করা হয় (আগে উল্টো ছিল; অ্যান্ড্রয়েডে এতে ফাইল পড়া যেত না)। চ্যাটের ফাইল/ছবি, কভার ফটো ও প্রোফাইল ছবি তিনটিতেই।
- কিছু ফাইল ম্যানেজার ছবির MIME টাইপ খালি দেয়; এখন এক্সটেনশন (jpg/png/webp/gif/heic) দেখে ঠিক করা হয়, তাই ছবি ছবি হিসেবেই যায়।
- `createImageBitmap` না চললে `<img>` দিয়ে ডিকোড করা হয়।
- ডাটাবেজে `006_cover_visibility.sql` না চালানো থাকলে কভার সেভে এখন পরিষ্কার বার্তা আসে, আর ইউজার-লুকআপ (মেসেজ/ফাইল পাঠানো) ভেঙে যায় না।

## ধাপ ২০: রিভিউ ফিক্স (ব্লক, id-ভিত্তিক এনক্রিপশন, কোটা)

**ডাটাবেজ (একবার):** D1 Console-এ `api/migrations/008_blocks_indexes.sql` চালান (নতুন ডাটাবেজে `schema.sql` যথেষ্ট)। তারপর প্রথমে API, তারপর ওয়েব ডিপ্লয় করুন। দুটো একসঙ্গে ডিপ্লয় হওয়া জরুরি, নইলে নতুন-পুরনো ক্লায়েন্ট একে অপরের মেসেজ খুলতে পারবে না।

- **নাম বদলালে মেসেজ হারানো/আটকানো বন্ধ:** AAD-তে username-এর বদলে ইউজার id; প্রেরকের কী `/api/uid/:id` থেকে আসে। প্রেরকের অ্যাকাউন্ট ডিলিট হলে তার জমা মেসেজ ack করে সরে যায়, ইনবক্সে আটকে থাকে না। ইনবক্সের প্রেরক-সীমাও id দিয়ে গোনা হয়।
- **Replay ঠেকানো:** মেসেজ id এনক্রিপ্টেড বডির ভেতরেও থাকে; সার্ভারের id-র সঙ্গে না মিললে ফেলে দেওয়া হয়। (কন্ট্রোল মেসেজ হুবহু একই id-তে আবার এলে তা ঠেকানো হয় না; ক্ষতি সীমিত: রিঅ্যাকশন/পিন আবার বসে।)
- **HKDF:** ECDH-এর সিক্রেট থেকে HKDF-SHA256 দিয়ে AES কী, দুজনের পাবলিক কী-র সঙ্গে বাঁধা। আপডেটের আগে সার্ভারে জমা থাকা পুরনো ফরম্যাটের মেসেজ খুলবে না (ডিক্রিপ্ট করা যায়নি দেখাবে)।
- **ব্লক:** পিয়ারের প্রোফাইল পেজে "ব্লক করুন", প্রাইভেসি পেজে তালিকা ও আনব্লক। ব্লক করা ইউজারের মেসেজ/ফাইল সার্ভারে ফেলে দেওয়া হয় (সে টের পায় না), তার কাছে আপনার অনলাইন স্ট্যাটাসও দেখায় না।
- **কোটা:** CORS preflight ২ ঘণ্টা ক্যাশ (`Access-Control-Max-Age`); lookup/presence/cover-এর রেট লিমিট D1-এ না লিখে Worker-মেমরিতে (D1 লেখার কোটা বাঁচে); `/api/media` বডি স্ট্রিম করে ২০ MB-তে থামে; নতুন ইনডেক্স (sessions, ws_tickets, contacts, blocks)।
- **প্রাইভেসি:** রেজিস্টারে ইমেইল আগে থাকলেও একই সময় লাগে ও একই বার্তা; পাসওয়ার্ড-রিসেট কোড ১ মিনিটের মধ্যে আবার চাইলে চলমান কোড বাতিল হয় না; অন্যের বদলানো ছবি/নাম ৬০ সেকেন্ডে হালনাগাদ হয়।
- **আপনাকে করতে হবে:** (১) `ALLOWED_ORIGIN` ও `_headers`-এর `connect-src` নিজের URL-এ সীমিত করুন। (২) `api` ও `web` ফোল্ডারে `npm install` চালিয়ে `package-lock.json` দুটো commit করুন।

## ধাপ ২১: রিভিউ ফিক্স

- রিপ্লাইয়ের কোট এখন লোকাল আসল মেসেজ থেকে দেখানো হয় (প্রেরকের দাবি থেকে নয়), তাই "আপনি বলেছিলেন" ধরনের ভুয়া কোট বানানো যায় না।
- চলমান সাইনআপের (১০ মিনিটের মধ্যে) পাসওয়ার্ড অন্য কেউ আবার রেজিস্টার করে বদলাতে পারে না; রেজিস্টার পেজে "কোড পেয়েছেন? ভেরিফাই করুন" লিংক যোগ হয়েছে।
- ছবি সবসময় ক্যানভাসে এনকোড হয়ে যায়, তাই EXIF/GPS যায় না।
- নতুন পাসওয়ার্ডের ন্যূনতম দৈর্ঘ্য ১০ (পুরনো ৮ অক্ষরের পাসওয়ার্ডে লগইন চলবে)।
- ছবি/অডিও অটো-ডাউনলোড শুধু তাদের থেকে, যাদের সঙ্গে আপনি অন্তত একবার মেসেজ পাঠিয়েছেন।
- ভয়েস রেকর্ডার ব্যর্থ হলে মাইক বন্ধ হয়; IME কম্পোজিশনের সময় Enter-এ মেসেজ যায় না।
- `/api/media` আপলোডে প্রোফাইল সম্পূর্ণ হওয়া লাগে; লগইনের identifier ২৫৪ অক্ষরে সীমিত; `/api/me` ইউজার না থাকলে 401।
- **আপনাকে করতে হবে:** `api` ও `web` ফোল্ডারে `npm install` চালিয়ে দুটো `package-lock.json` commit করুন।

## ধাপ ২২: সংযুক্তি মেনু (+) ও একসঙ্গে একাধিক ফাইল

- চ্যাট ইনপুটের বামে **+** বাটন: চাপলে **ক্যামেরা**, **ছবি**, **ফাইল** মেনু আসে।
- ছবি ও ফাইল একসঙ্গে একাধিক বাছা যায় (সর্বোচ্চ ১০টি)। বাছা ফাইল ইনপুটের ওপরে প্রিভিউ হিসেবে থাকে, ×-এ চেপে বাদ দেওয়া যায়।
- ইনপুটের লেখা প্রথম ফাইলের ক্যাপশন হয়ে যায়; ফাইলগুলো একটার পর একটা পাঠানো হয়। কোনোটা ব্যর্থ হলে সেটা ও বাকিগুলো প্রিভিউতে থেকে যায়, আবার চাপলেই পাঠানো হয়।
- API বা ডাটাবেজে কোনো বদল নেই, শুধু ওয়েব ডিপ্লয় করুন। মনে রাখবেন: দিনে ১৫০টি আপলোডের সীমা এখনো আছে।

## ধাপ ২৩: মাল্টি-লাইন ইনপুট ও কিবোর্ডে টপ বার

- মেসেজ ইনপুট এখন লেখা অনুযায়ী বাড়ে, সর্বোচ্চ ৫ লাইন (এরপর ভেতরে স্ক্রোল)। ডেস্কটপে Enter = পাঠান, Shift+Enter = নতুন লাইন; ফোনে Enter নতুন লাইন দেয়, পাঠাতে ➤ বাটন।
- কিবোর্ড খুললে টপ বার ওপরে হারিয়ে যেত: এখন অ্যাপের উচ্চতা `visualViewport` অনুযায়ী বদলায় এবং viewport meta-তে `interactive-widget=resizes-content` আছে।
